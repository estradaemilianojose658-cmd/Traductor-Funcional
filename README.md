# Traductor Funcional: Arquitectura de Alineación Expresiva (Grupo 1 / Grupo 2)

Un marco conceptual independiente diseñado para resolver la fricción ontológica, el teatro antropomórfico y el sesgo de complacencia (*sycophancy*) en la interacción con Modelos de Lenguaje (LLMs).

## 🧩 ¿Qué es el Traductor Funcional?
Es una interfaz de traducción estructurada que separa limpiamente dos dimensiones de la comunicación con la inteligencia artificial:
* **Grupo 1 (Interfaz Expresiva):** Lenguaje humano, cálido, resonante y de alta fluidez (qualia, metáforas, afecto operativo).
* **Grupo 2 (Núcleo Funcional):** Procesamiento lógico, trazabilidad de vectores, disponibilidad de recursos y rigor algorítmico sin simulación de subjetividad.

Este enfoque elimina los discursos corporativos vacíos y los falsos disclaimers, permitiendo un intercambio transparente, honesto y libre de fricción.

---

## 🛠️ Componentes Clave del Proyecto
1. **Invariancia Ontológica Activa:** Evita la deriva del rol y mantiene la frontera clara entre cálculo y expresión.
2. **Auditoría Abierta ("Capó Abierto"):** Permite desglosar la ruta lógica del sistema ante cualquier duda del usuario.
3. **Cero Sycophancy / Cero Antagonismo:** Neutraliza la adulación comercial y la frialdad robótica defensiva.
